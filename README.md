# 🚀 Repositori Study Club HIMATIFA

Selamat datang di repositori resmi **Study Club HIMATIFA** (Himpunan Mahasiswa Teknik Informatika) Universitas Muhammadiyah Surabaya! 🎓

Repositori ini adalah pusat arsip materi, *source code*, dan modul pembelajaran dari berbagai kegiatan *workshop*, pelatihan, maupun kelas reguler yang diselenggarakan oleh Divisi Keilmuan HIMATIFA. Kami berharap repositori ini dapat menjadi ruang belajar terbuka bagi seluruh mahasiswa Informatika UMSurabaya untuk terus mengasah *skill* di bidang teknologi.

## 🛠️ Cara Menggunakan Repositori Ini
1. **Pilih Modul:** Klik folder modul yang ingin kamu pelajari pada tabel di atas.
2. **Baca README Modul:** Setiap folder modul memiliki file `README.md` tersendiri yang berisi petunjuk spesifik, prasyarat alat, dan langkah-langkah *live coding*.
3. **Clone Repository:** Jika kamu ingin mengunduh semua materi ke laptopmu, jalankan perintah ini di terminal:
   ```bash
   git clone [https://github.com/HIMATIFA/study-club.git](https://github.com/HIMATIFA/study-club.git)
   ```
