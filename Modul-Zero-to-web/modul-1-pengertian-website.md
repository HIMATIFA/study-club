# Modul 1: Pengertian Website & Cara Kerjanya

Selamat datang di Modul "Zero to Web"! Sebelum kita mulai mengetik kode, kita perlu memahami bagaimana sebenarnya sebuah website bekerja di internet.

## 1. Bagaimana Cara Kerja Website?
Website bekerja melalui komunikasi antara dua pihak utama, yaitu **Klien** dan **Server**[cite: 30].

*   **Client (Klien):** Perangkat pengguna yang terhubung ke internet (seperti laptop atau ponsel) dan perangkat lunak pengakses web (seperti browser Chrome atau Firefox)[cite: 30].
*   **Server:** Komputer yang menyimpan halaman web, aplikasi, atau data[cite: 30].

**Alur Sederhana (Konsep Request-Response):**
1. Setiap klien dan server memiliki alamat unik di internet yang disebut IP Address[cite: 32].
2. Saat kamu mengetik nama web di browser, klien akan mengirimkan permintaan (*requests*) ke Server[cite: 31, 32].
3. Server memprosesnya, lalu mengirimkan jawaban (*responses*) kembali ke klien dalam bentuk file web yang kemudian ditampilkan oleh browser[cite: 31, 32].

> **💡 Analogi Restoran:**
> Bayangkan Klien adalah **Pelanggan** di restoran, *Request* adalah **Pesanan**, Server adalah **Dapur**, dan *Response* adalah **Makanan** yang disajikan ke meja Anda.

## 2. Tiga Pilar (Lapis) Web
Untuk membangun sebuah website, kita membutuhkan tiga teknologi utama yang bekerja sama[cite: 33]:

1. **HTML (Kerangka):** Bertugas membuat struktur dan menyusun halaman[cite: 33]. Ibarat **tulang** pada tubuh manusia[cite: 34].
2. **CSS (Tampilan):** Bertugas mengatur warna, jarak, dan tata letak (*layout*)[cite: 33]. Ibarat **kulit** atau pakaian yang mempercantik[cite: 34].
3. **JavaScript (Interaksi):** Bertugas memberikan perilaku (*behavior*) dan logika agar halaman menjadi interaktif[cite: 33]. Ibarat **otak** penggerak pada manusia[cite: 34].

Ketiga bahasa inilah yang akan kita pelajari pada modul-modul berikutnya!
