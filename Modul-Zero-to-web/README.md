# 🚀 Zero to Web: Modul Study Club HIMATIFA

Selamat datang di repositori modul pembelajaran **"Zero to Web: Membuat Website Pertama dari Nol"**. Repositori ini berisi panduan langkah demi langkah dan *source code* untuk membangun website portofolio pribadi sederhana menggunakan HTML, CSS, dan JavaScript murni.

## 📁 Struktur Modul
Silakan pelajari materi secara berurutan melalui tautan berikut:
1. [Modul 1: Pengertian Website & Cara Kerjanya](modul-1-pengertian-website.md)
2. [Modul 2: HTML (Membangun Kerangka)](modul-2-html.md)
3. [Modul 3: CSS (Mempercantik Tampilan)](modul-3-css.md)
4. [Modul 4: JavaScript & DOM (Memberikan Interaksi)](modul-4-javascript.md)

## 🛠️ Persiapan Alat (Prerequisites)
Sebelum mulai ngoding, pastikan kamu sudah menyiapkan alat tempur berikut:
* [Visual Studio Code](https://code.visualstudio.com/) (Teks Editor)
* Web Browser (Google Chrome, Microsoft Edge, atau Mozilla Firefox)
* Ekstensi VS Code: **Live Server** (oleh Ritwick Dey) agar tampilan web bisa otomatis *refresh* saat kode disimpan.

## 🏃‍♂️ Cara Menjalankan Project
1. *Clone* repositori ini atau *Download ZIP*.
2. Buka folder *project* menggunakan Visual Studio Code.
3. Siapkan foto terbaikmu, beri nama `foto-profil.jpg`, dan letakkan di dalam folder yang sama.
4. Buka file `index.html`.
5. Klik kanan pada layar kode, lalu pilih **"Open with Live Server"**.
6. Selesai! Website portofoliomu akan terbuka di browser.
